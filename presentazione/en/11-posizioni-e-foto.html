Feature 4 · simulation

Balanced positions and several photos of the same object

Two measures to tell whether the child really recognizes the object: the correct answer is not always in the same place, and the same object appears in different photos.

In each block of trials the correct object takes each place once. With variations the object's photo changes, but the list always shows the same photo as the correct card: the appearance changes, not the task.

What it does not prove: recognizing a new photo on the tablet is not the same as recognizing the real object. That is what feature 5 is for.
