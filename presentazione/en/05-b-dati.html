B · Understanding what the child really knows

Organizing trials and reading the data so that a result says what the child has learned, and nothing else. For each choice, the literature that supports it.

Balanced positions, no hints

In the platform. The correct object takes each place the same number of times, and no frame or colour gives the answer away. The same object can appear in different photos.

Why: what the literature says. The correct stimulus must be placed in each position in equal proportions, otherwise the child may learn the place instead of the object. Prompts that highlight an option are discouraged.

Grow and LeBlanc, 2013

How far it goes. The recommendations are written for receptive language. And the game's only prompt is a highlight: a declared limit.

Prompts recorded, prompted answers apart

In the platform. On every attempt the game saves which prompts were present. An answer given with a prompt that reveals it does not count as independent.

Why: what the literature says. Across 46 experiments, procedures for fading prompts are generally effective. Prompts should be faded systematically, so that the child does not come to depend on them.

Cengher et al., 2018 · Grow and LeBlanc, 2013

How far it goes. The game does not yet fade prompts progressively: on this the analyst's opinion is needed.

Results with their margin of uncertainty

In the platform. With few trials the game does not trust the raw percentage: it decides on the most cautious value of an interval, and asks for more data before proposing a change.

Why: what the literature says. With little data the interval most used in textbooks has erratic coverage; for small samples the Wilson interval is recommended.

Wilson, 1927 · Brown, Cai and DasGupta, 2001

How far it goes. The thresholds used are provisional, to be tuned with the analyst.
